arkdevs brand kit (brush A)
===========================
Colours
  Black  #111111
  Red    #E10600
  White  #FFFFFF
Typeface
  Sora SemiBold (600), tracking -3%. Free from Google Fonts. All logo text is outlined, so no font install is needed to use the files.

Folders
  horizontal/  main logo (symbol + wordmark). Use this first.
  stacked/     symbol above wordmark, for square spaces.
  symbol/      the A mark on its own, transparent background.
  icon/        mark on a rounded tile (app icons, avatars).
  wordmark/    "arkdevs" text only.
  favicon/     favicon.ico (16-256px), favicon.svg, apple/android icons, manifest, <head> snippet.
  social/      profile avatars, OG image, X, LinkedIn and YouTube banners.
  png/         PNG exports of everything above, in several widths.

Usage
  - Red is the accent: keep it on the swoosh only.
  - On dark backgrounds use the "-white" versions; on photos or colour use a mono version.
  - Clear space: at least the height of the swoosh on every side.
  - Minimum size: 24px for the symbol. The favicon uses a heavier small-size cut for 16-32px.
